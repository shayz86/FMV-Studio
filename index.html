Status ekstraksi & editor

Belum diaktifkan: parser format internal harus terverifikasi terlebih dahulu.
  1. Identifikasi wrapper — petakan header, panjang data, dan kemungkinan blok.
  2. Validasi kompresi — signature saja tidak cukup; frame harus berhasil didekompresi dan panjangnya masuk akal.
  3. Ekstraksi aman — tampilkan file/folder hanya setelah struktur terbukti.
  4. Editor tabel — dibuat berdasarkan tipe data yang benar-benar ditemukan.
  5. Repack FMV — belum tersedia sampai aturan serialisasi dan kompatibilitas game dapat diuji.

Jangan gunakan prototype ini untuk menimpa save game asli. Simpan salinan cadangan sebelum pengujian.
